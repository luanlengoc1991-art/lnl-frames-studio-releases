# LNL Frames Studio — bản cài đặt

Tải bản mới nhất: **[Releases → Latest](https://github.com/luanlengoc1991-art/lnl-frames-studio-releases/releases/latest)**, chạy `LNL-Frames-Studio-Setup-x.y.z.exe`.

- App tự kiểm tra bản mới khi mở và mỗi 4 giờ, tự tải về và cài khi khởi động lại.
- Cần Claude Code (`claude`) đã đăng nhập bằng gói claude.ai và `ffmpeg`.
- Windows có thể báo SmartScreen vì app chưa ký số: chọn **More info → Run anyway**.

Chỉ tài khoản `luanlengoc1991-art` phát hành được bản cập nhật. Repo này chỉ chứa bản cài; mã nguồn ở repo riêng tư.
